# Suisse Speech OpenAI TTS

OpenAI-compatible speech synthesis backed by Suisse Speech, packaged as a
Home Assistant add-on for **amd64** and **aarch64**.

Install the add-on, then connect the `sfortis/openai_tts` integration using its
Custom provider. Native `studio` / `swift` models and Swiss German dialects
are supported. See the Documentation tab for setup and credential options.

Source and issues: https://github.com/splattner/openai-tts-suissespeech-adapter
